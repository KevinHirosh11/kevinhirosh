Newtonian Telescope Simulator

An OOP-based Python optical simulator paired with real-time 3D Blender mechanical rotation models.

This academic project models light-ray geometry, primary and secondary mirror reflections, focal points, and observer positions. The Python application uses modular classes and a PyQt interface, while Blender provides interactive 3D telescope rotation.

Stack Used

  • Python 3
  • PyQt5
  • Blender 3D
  • NumPy
